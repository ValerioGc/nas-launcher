<h2 id="configuration">Sign-in and configuration</h2>

<h3 id="first-setup">Initial setup</h3>
<p>The wizard prepares the NAS before the normal interface is available. Start its package's
entry script on the machine, as described in the installation manual, and complete setup in the
browser. Choose the administrator account, NAS name, language/theme, networking, optional empty
data disks, release token, and summary. Wi-Fi is optional with a cable. The wizard installs the
NAS, and the interface provisions catalog applications before displaying sign-in.</p>

<h3 id="sign-in">Sign-in</h3>
<p>Use the administrator account's username and password. By default, five failed attempts from
one address lock sign-in for one minute. Adjust attempts/duration or disable lockout in
<strong>Security Center > Access</strong>. Sessions expire after 30 inactive minutes or 12 hours
from sign-in and survive a NAS restart.</p>
<p><strong>Forgot password?</strong> appears only when email recovery is enabled with a verified
address. Enter the username to request a code valid for 15 minutes at the address configured in
<strong>Settings > Account</strong>. A valid code sets a new password and closes all sessions.
The page responds identically when no recovery address exists.</p>

<h3 id="desktop">Desktop</h3>
<p>Drag desktop icons to reorder them. With the keyboard, <kbd>Alt</kbd> and arrow keys move the
selected icon left or right. Ordering persists across restarts.</p>

<h3 id="settings">Settings</h3>
<ul>
  <li><strong>General</strong> controls language, light/dark/system appearance, the palette for
  each theme type, accent color, desktop icon size (small through extra large), and background.
  Changing palettes preserves the chosen accent.</li>
  <li><strong>Account</strong> manages username, password, and recovery email. Changes require
  the current password. Renaming affects sign-in only; the terminal user and disk directories
  retain their setup names. A password change closes other sessions. Email recovery is disabled
  until explicitly enabled with password confirmation. Set and verify a recovery address using
  the code sent by the NAS. The <strong>Email</strong> application must have an outgoing mail
  server configured before messages can be sent.</li>
  <li><strong>Network</strong> shows the active connection, address, gateway, DNS, adapters, and
  Wi-Fi networks. An unused adapter can be disabled and is re-enabled automatically if the NAS
  loses connectivity. With a cable connected, Wi-Fi remains visible but is not joined.</li>
  <li><strong>Power</strong> schedules shutdown, restart, and power-on. Scheduling applications,
  such as Backup, read these rules to avoid periods when the NAS is off. Connected-display idle
  timeout ranges from 1 to 240 minutes, default 10; input wakes it and requires sign-in again.
  Scheduled shutdown/restart waits up to an hour for application operations, then interrupts
  unfinished work. NAS updates, system-package installation, and disk operations are always
  awaited. Notifications explain either case. Header Restart/Shut down actions list interrupted
  tasks and require explicit confirmation without a countdown. Confirmation remains unavailable
  during privileged updates or disk work.</li>
  <li><strong>Updates</strong> manages Debian packages and NAS components, described below.</li>
  <li><strong>Recovery and reset</strong> exports general settings without NAS name, allowed
  addresses, sign-in policy, power rules, widget refresh preferences, desktop, and supported
  application settings selected in the export dialog. Networking, NAS name, account, token, and
  application data are excluded. Export requires the account password. A separate optional
  file password encrypts the export; otherwise it is readable JSON. Import requires account
  confirmation and, for encrypted files, their file password, then replaces included settings
  and allowed addresses. <em>Reset the NAS</em> permanently removes accounts/sessions, installed
  applications and their data, the terminal user/home, launcher preferences, and release token.
  Data disks and their files remain intact. Original hostname, networking, DNS, Samba, and service
  states are restored, and NAS firewall tables are removed. Debian package upgrades remain
  installed. The wizard remains available for fresh setup. Hostname/address changes may disconnect
  the browser; reopen the restored address. Reset requires the installed wizard and original
  configuration backup. Older installations without that backup require original-state recovery
  or a VM snapshot rather than simply reinstalling.</li>
</ul>

<h3 id="security">Security Center</h3>
<p><strong>Security Center</strong> is installed during initial setup. <strong>Access</strong>
contains failed-sign-in notifications, lockout settings, and allowed NAS addresses. Save appears
only after edits; address additions/removals apply immediately. Rules remain active while the
application is closed. <strong>Security log</strong> records refused sign-ins while their logging
is enabled. <strong>Devices</strong> manages optional certificate-only access, mTLS, and each
admitted device's downloadable, renewable, or revocable certificate.</p>
<p><strong>Certificates</strong> shows the HTTPS certificate issuer, covered addresses, and
validity. It explains insecure-connection warnings caused by plain HTTP, an uncovered address,
or an untrusted NAS authority. Download the authority and follow installation instructions for
Windows, macOS, Linux, Firefox, Android, or iPhone. Add addresses used through a domain, VPN, or
forwarding, renew the certificate immediately, or install a custom PEM certificate and key.
Changes require the account password and apply from the next connection.</p>

<h3 id="search">Search</h3>
<p>Global search finds applications, settings entries, and files. Tabs limit results to one type
or search everything. File search exposes type/extension filters and uses installed applications
that provide search. Without a provider there are no file results. Selecting a result opens its
application or settings section.</p>

<h3 id="updates">Updates</h3>
<p><strong>Settings > Updates</strong> has two sections.</p>
<h4>System updates</h4>
<p>The list shows Debian packages with installed and available versions. <em>Check updates</em>
refreshes package data. Select packages using row switches and choose <em>Update selected</em>.
During installation, the list stays visible but disabled. Results arrive as notifications.
Only one package-update job runs at a time.</p>
<h4>NAS updates</h4>
<p>The page lists launcher/interface, gateway, and wizard with installed/available versions,
repositories, and token status. Configure the token during setup or in App Manager settings.
<em>Check updates</em> checks all components together.</p>
<p><em>Update all</em> opens a confirmation listing changes and then displays progress. Components
update together after a database/configuration backup, in wizard, gateway, launcher order.
The NAS is temporarily unavailable and <strong>reboots when the launcher changes</strong>.
The page reloads after readiness. Any failed component restores the previous versions; the window
reports rollback and notifications contain the reason.</p>
<p>Factory reset first tries to update the wizard so the next setup uses the latest version.</p>

<h3 id="notifications">Notifications</h3>
<p>New notifications appear at the lower right. Informational notices dismiss after six seconds;
warnings/errors after twelve. The colored bottom border shows remaining time. Hovering pauses
the countdown.</p>
<p><strong>Notifications</strong> stores history with severity, source, text, and unread filters.
Reset filters appears only with active filters. Each row identifies its originating application
or system area. The magnifying-glass action opens the detailed notification log in Log and stays
disabled until that application is installed.</p>

<h3 id="terminal">Terminal</h3>
<p>The system application <code>nas-system-terminal</code>, available in App Manager, provides
<strong>Console</strong> and <strong>System log</strong>. Console runs an interactive shell as
the unprivileged wizard-created user. Use <code>su - nas</code> and the Linux administrator's
password to enter that account and use its existing sudo permissions. System log follows the
machine journal. Preferences control colors, font, line spacing, and transparency; 100%
transparency exposes the desktop background fully.</p>
