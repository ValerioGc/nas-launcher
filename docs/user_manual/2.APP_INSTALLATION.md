<h1 id="installing-applications">Installing applications</h1>

<h2 id="preinstalled-applications">Preinstalled applications</h2>

System applications appear in App Manager at first use. NAS builds may include additional
packages. They appear under **Installed** without another download.

<h2 id="token">Token</h2>

Releases use the token entered during initial setup or through App Manager's settings gear.
Installation/update controls indicate when a token is required and where to configure it.

<h2 id="installing-from-catalog">Installing from the catalog</h2>

Open **App Manager > Available**, select an application, choose **Install**, and confirm. The
start message dismisses after a few seconds while the application icon shows ongoing work.
The completed application appears under **Installed** and in the application menu. Failures
appear in App Manager and notifications.

Choose **Check updates** under **Installed** to find newer releases. **Update all** installs
them sequentially; **Update selected** updates only the selected application.

The **Automatic updates** preferences contain two groups.

- **Periodic checks** run hourly, daily, or weekly and create notifications for new versions.
- **When App Manager opens** can check on every opening. Enabling immediate installation together
  with that option installs detected updates without another action. Private releases require
  the configured token.

<h2 id="uninstalling">Uninstalling</h2>

Select an installed application and choose **Uninstall**. Confirmation offers to delete its files
and data, selected by default. Clear that option to retain data for a later reinstallation.

<h2 id="catalog-and-logos">Catalog and logos</h2>

App Manager settings list installable applications with repositories, release assets, logos,
and categories. Media, Files, Storage, Network, Security, Utilities, and Development become menu
folders alongside **All apps** and **System**. Upload SVG, PNG, JPEG, or WebP logos up to 256 KB
through the catalog entry form. They are stored on the NAS and replace the default logo for
known applications. Installed applications use their packaged icon when provided.

<h2 id="opening-applications">Opening an application</h2>

Each application opens in a launcher tab on the same NAS address, without DNS, router, or client
configuration. An unavailable application is identified in its tab and can be started/restarted
from App Manager. Application access uses the signed-in NAS session.
